# Изображения «Свои не уезжают»

Публичный репозиторий выбранных обложек, иллюстраций и миниатюр для Дзен-канала «Свои не уезжают» (сериал «Уезжать запрещается»). Редакционная система, тексты глав, промпты, паспорта, референсы и журналы остаются в приватном `MaksZakharov/svoi_ne_uezzhayut`.

Устроен по образцу `MaksZakharov/limita_images`.

## Структура

```text
Статьи/
  сезон-01/
    глава-001/
      cover_v01.jpg
      preview_v01.jpg
      illustration-01_v01.jpg
    глава-002/
      cover_v01.jpg
      preview_v01.jpg
Канал/
  avatar_v01.jpg
  cover_v01.jpg
```

Это пример путей, а не существующие изображения. Номер главы сквозной и совпадает с кодом в приватном репо: `глава-001` = `Г-001`. Сезон: `сезон-NN`. Версии начинаются с `v01`; при правке создаётся новая версия, прежняя не перезаписывается и не удаляется. `Канал/` — аватар и шапка канала.

Правила:
1. У каждой главы своя обложка (`cover`). Одну обложку на две главы не ставить.
2. Обложки светлые, герои крупно и в средней трети кадра, эмоция как в заголовке.
3. Только картинки встроенной генерации бота, с очищенными метаданными. Это вымышленные иллюстрации, не фотографии.
4. Выкладывать только выбранные изображения, пригодные для публичного доступа; никаких персональных данных и внутренних файлов.

Ссылки для Markdown и пакета Дзена — только raw:
`https://raw.githubusercontent.com/MaksZakharov/svoi_ne_uezzhayut_images/main/Статьи/сезон-01/глава-001/cover_v01.jpg`

Кириллицу допустимо percent-encode. Помимо JPG допустимы JPEG, PNG и WebP. Просмотр GitHub `blob/`, другие репозитории/ветки и локальные пути не являются ссылками для пакета Дзена. Перед передачей открыть raw-ссылку и проверить доступность, настоящее изображение и маленькое превью.

Публикует в Дзене только Макс; черновики создаёт Публикатор. Этот репозиторий ничего не публикует автоматически.
